INSTALL ON YOUR LAPTOP
1. Stop the running Flask application with Ctrl+C.
2. Keep a backup of your current app.py.
3. Replace ONLY app.py in the project you actually run with the app.py in this ZIP.
4. Keep your existing instance/readings.db so your latest readings remain.
5. In the terminal, open the folder containing the replaced app.py.
6. Run: python app.py
7. Open http://127.0.0.1:5000, log out if necessary, and refresh.
8. Select Engineering and use engineering as the password.

ONLINE VERSION
Update the app.py in the source used by Render and redeploy.
Editing your laptop copy alone does not change the Render website.

TROUBLESHOOTING
This corrected app.py contains no "Sign-in is not configured" message.
If that message still appears, you are viewing a different running copy or an old deployment.
